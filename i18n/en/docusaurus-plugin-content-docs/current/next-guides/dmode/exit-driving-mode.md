# Exiting Driving Mode

There are two ways to exit Driving Mode:

Method 1: Tap the first icon in the DOCK area to open the app list, then select the first icon, "Exit".

<img
  src={require('./img/exit-driving-mode-1.jpg').default}
  width="400"
/>

Method 2: Tap the HiCar Live Window at the top, then tap the "Exit" icon in the "Driving mode entered" notification banner.

<img
  src={require('./img/exit-driving-mode-2.png').default}
  width="400"
/>
