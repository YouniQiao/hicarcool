# 退出驾驶模式

退出驾驶模式，有2种方式：

第一种：点击Dock区第一个图标，进入更多应用列表，然后选择第一个图标“退出”。

<img
  src={require('./img/exit-driving-mode-1.jpg').default}
  width="400" 
/>

第二种：在顶部点击HiCar实况窗，点击“已进入驾驶场景”的通知横幅中的“退出”图标。

<img
  src={require('./img/exit-driving-mode-2.png').default}
  width="400" 
/>
