# 截屏

Next HiCar截屏功能依赖手机上的驾驶模式功能。如果您目前不了解HiCar驾驶模式，您可以点击[驾驶模式简介](../dmode/driving-mode.md)了解。

当您在连接Next HiCar的状态下，打开手机上的驾驶模式功能，您将看到驾驶模式界面变成如下Next HiCar遥控器的样式，此时，您点击“截屏”按钮即可完成对HiCar界面截屏。截取的图片保存在手机相册中。

您可以在Next HiCar已连接的状态下，通过以下两种方式进入到找到截屏功能：
1. 点击手机界面顶部实况窗中的HiCar弹框。
2. 依次选择“设置 - 多设备协同 - HUAWEI HiCar -驾驶模式”。
